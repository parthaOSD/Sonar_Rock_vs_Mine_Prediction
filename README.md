## Sonar_Rock_vs_Mine_Prediction

## Overview
  This project demonstrates the application of Machine Learning techniques in sonar systems to classify underwater objects as either rocks or mines.
  It also compares multiple classification models to identify the best-performing model.

## Dataset Used
   Kaggle Sonar Dataset

## Objective
  The objective of this project is to classify underwater objects as rocks or mines based on sonar signal data and 
  compare different machine learning classification models to determine the most effective model.

## Machine Learning Model Used
   Logistic Regression, Random Forest Classifier and SVM.

## Evaluation Metrics
   1) Train Accuracy
   2) Test Accuracy

## Results
   The machine learning models were trained and evaluated to classify underwater objects as either rocks or mines. 
   The performance of Logistic Regression, Random Forest, and SVM was compared using training and testing accuracy. 
   Based on the experimental results, SVM achieved the best overall performance and was selected as the most suitable model for this dataset.

## Technlogies Used
  1) Numpy
  2) Pandas
  3) Scikit-learn
